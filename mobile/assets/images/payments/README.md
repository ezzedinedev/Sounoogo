# Logos des moyens de paiement

Marques déposées de leurs propriétaires respectifs (Wave Mobile Money, Orange), utilisées
uniquement pour identifier le moyen de paiement choisi.

- `wave.png` — icône publiée sur https://www.wave.com
- `orange_money.png` — logo Orange publié sur https://www.orange.bf

À remplacer par les éléments du kit marchand officiel fourni lors de la signature des contrats.
