# Identité SUNOOGO

**Logo de référence : bulle blanche sur fond violet** (`png/logo-lockup-violet.png`).

| Fichier | Usage |
|---|---|
| `logo-badge.svg` | Favicon, en-tête du site sur fond blanc, avatar réseaux sociaux |
| `logo-mark-inverse.svg` | Bulle blanche seule, sur fond violet (footer, back-office, splash) |
| `logo-mark.svg` | Bulle violette seule, usage secondaire sur fond blanc |
| `app-icon.svg` / `png/app-icon-*.png` | Icône des applications Android / iOS |
| `png/logo-lockup*.png` | Logo complet avec signature |

Symbole : une bulle de parole (être écouté·e) dans laquelle se lève un soleil (l'espoir qui revient).

## Couleurs

| Token | Hex | Usage |
|---|---|---|
| Violet 700 (principal) | `#602fb8` | Boutons, liens, fonds de marque |
| Violet 800 | `#4c2494` | Survol, dégradés |
| Violet 950 (nuit) | `#210e40` | Textes, pied de page, back-office |
| Violet 50 | `#f8f5ff` | Fonds doux |
| Lilas 200 | `#ebd6fb` | Accent sur fond violet |
| Blanc | `#ffffff` | Fond principal |
| Rouge SOS | `oklch(52% 0.19 27)` | Réservé à l'urgence |

## Typographies

- Titres : **Fraunces** 600 (serif chaleureuse)
- Texte : **Figtree** 400–700
