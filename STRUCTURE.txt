# SUNOOGO — structure du monorepo

```
SUNOOGO/
├── api/              # Backend FastAPI (Python)
├── mobile/           # Application Expo / React Native
├── admin/            # Back-office React + Vite
├── web/              # Site vitrine Next.js (App Router)
├── packages/
│   └── shared/       # Design tokens & utilitaires partagés
├── docs/             # PRD, OpenAPI, ADR, design system
└── docker-compose.yml
```

## Commandes (depuis la racine)

| Cible | Commande |
|-------|----------|
| API | `cd api` puis uvicorn |
| Admin | `npm run admin:dev` |
| Mobile | `npm run mobile:start` |
| Web | `npm run web:dev` |
| Tests API | `npm run api:test` |
